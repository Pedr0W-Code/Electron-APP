# Electron SPA App

A **Single Page Application (SPA)** desktop app built with **Electron**, using **JavaScript, HTML, and CSS**.

---

## 🚀 About the Project

This project is a **desktop application built with Electron** and designed as a **Single Page Application (SPA)**.  
All content is dynamically handled in a single window without page reloads.

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repo-name.git
```
### 2. Enter project folder
```bash
cd Electron-APP
```
### 3. Install dependencies
```bash
npm install
```
### 4. Run the app
```bash
npm start
```
